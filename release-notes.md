# 1.0.0

Promotes 1.0.0-beta.3 to the stable 1.0 release with no library behavior changes.

- Updates documentation, release metadata, and the mod icon for 1.0.
- Supports Harmony 2 on Mono/net472, Microsoft CLR/net472, and Microsoft CLR/net10.0, and Harmony 3 on Microsoft CLR/net10.0.

The RimWorld mod supports 1.6 and 1.7 unstable. It bundles Harmony 2.4.1 for RimWorld 1.6 and Harmony 3.0.0-rc.3 for RimWorld 1.7.
